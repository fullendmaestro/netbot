# Netbot

Netbot is an intelligent IT infrastructure assistant designed to help engineers monitor, manage, and automate their network infrastructure using AI.

## Architecture

The project consists of two main components that communicate via Firebase Firestore:

1. **Desktop App (`/desktop`)**: An Electron-based desktop application built with React, TypeScript, and TailwindCSS. It provides the user interface for the assistant and handles direct, local connections (SSH, Telnet, Serial) to network devices.
2. **Agent Backend (`/agent`)**: A Python-based backend powered by the Google ADK (Agent Development Kit). It hosts the LLM agent, processes natural language requests, and dispatches terminal commands to the desktop app via Firestore.

## Prerequisites

- **Bun**: Used for the desktop app (`npm install -g bun`).
- **uv**: Used for the Python agent backend (`pip install uv`).
- **Firebase**: A Firebase project configured with Firestore.

## Getting Started

You will need to run both the frontend and backend concurrently for the application to function.

### 1. Start the Desktop App

```bash
cd desktop
bun install
bun run dev
```

### 2. Start the Agent Backend

```bash
cd agent
uv run uvicorn main:app --host 0.0.0.0 --port 8000
```

## Infrastructure Deployment

Netbot integrates with external network management and simulation tools. Deployment scripts for GCP environments are provided in the `/scripts` directory.

### Deploying the GNS3 Server

1. **Provision the GCP Infrastructure:**
   Run the following `gcloud` commands to configure the firewall and deploy the Spot instance:

```powershell
gcloud compute firewall-rules create allow-gns3 `
    --direction=INGRESS `
    --priority=1000 `
    --network=default `
    --action=ALLOW `
    --rules="tcp:3080,tcp:2222-2250,tcp:5000-5050" `
    --source-ranges="0.0.0.0/0" `
    --target-tags=gns3-server

gcloud compute instances create gns3-server `
    --zone=us-central1-f `
    --machine-type=n2-standard-4 `
    --enable-nested-virtualization `
    --provisioning-model=SPOT `
    --image-family=ubuntu-2204-lts `
    --image-project=ubuntu-os-cloud `
    --boot-disk-size=60GB `
    --tags=gns3-server

```

2. **Install GNS3:**
   SSH into the server (`gcloud compute ssh gns3-server --zone=us-central1-f`) and run the setup script:

```bash
./scripts/install_gns3.sh

```

### Deploying the LibreNMS Server

1. **Provision the GCP Infrastructure:**

```powershell
gcloud compute firewall-rules create allow-librenms `
    --direction=INGRESS `
    --priority=1000 `
    --network=default `
    --action=ALLOW `
    --rules="tcp:80,tcp:443" `
    --source-ranges="0.0.0.0/0" `
    --target-tags=librenms-server

gcloud compute instances create librenms-server `
    --zone=us-central1-f `
    --machine-type=e2-medium `
    --provisioning-model=SPOT `
    --image-family=ubuntu-2204-lts `
    --image-project=ubuntu-os-cloud `
    --boot-disk-size=40GB `
    --tags=librenms-server

```

2. **Install LibreNMS:**
   SSH into the server, elevate to root, and run the setup script:

```bash
sudo su
./scripts/install_librenms.sh

```

3. **Complete Configuration:** Navigate to `http://<YOUR_VM_EXTERNAL_IP>/install` to finalize the web UI setup using the default database credentials generated by the script (`librenms` / `librenms_password`).

## Features

- **Intelligent Assistant**: Interact with your network devices using natural language.

- **Local Execution**: Terminal commands (SSH, Telnet, Serial) are executed locally on your machine via the Electron app, ensuring secure access to your private network infrastructure.

- **Real-time Sync**: Device configurations and command executions are synchronized in real-time across the platform using Firestore.
